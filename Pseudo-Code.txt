Input:
    Dataset D = {Xi, Yi}
    CNN backbone C (ResNet101)
    Transformer backbone T (ViT-B/16)
    Training epochs E
    Learning rate α
    Batch size B

Output:
    Trained hybrid classification model M

Begin

1. Set random seed 
2. Initialize CNN backbone C with pretrained ImageNet weights
3. Initialize Transformer backbone T with pretrained weights
4. Replace final classification layers of C and T
5. Define Global Average Pooling (GAP) for CNN branch
6. Define Patch Embedding + Transformer Encoder for ViT branch

7. For each image Xi in Dataset D:
        a. Resize Xi → 224 × 224
        b. Apply augmentation:
              - shear (0.2)
              - zoom (0.2)
              - horizontal flip
              - vertical flip
        c. Normalize using dataset mean & std

8. Forward Propagation:
        CNN_features  = GAP(C(Xi))
        ViT_features  = T(Xi)
        Fused_features = Concatenate(CNN_features, ViT_features)

9. Apply fusion block:
        F1 = Conv(1×1) + ReLU
        F2 = Conv(3×3) + ReLU
        F3 = Global Average Pooling

10. Final Classification:
        Output = Softmax(Dense(F3))

11. Compute Loss:
        L = cross entropy and weighted Cross-entropy (Output, Yi)

12. Backpropagation:
        Update parameters using Adam optimizer (lr = 0.001)

13. Repeat steps 7–12 for E epochs

End
